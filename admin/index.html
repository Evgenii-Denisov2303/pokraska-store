POKRASKA.STORE Контентная админка

Редактирование сайта через JSON-контент: шапка, главная, каталог, услуги, автоматика, галерея, цены, оплата и контакты.

Как запускать

  1. Открой терминал в проекте.
  2. Запусти node scripts/admin-server.js.
  3. Открой http://localhost:4173/admin/.

Если сервер не запущен, админка останется в режиме чтения и позволит скачать JSON вручную.

Для доступа заказчика запусти сервер с ADMIN_USERNAME и ADMIN_PASSWORD. Подробности: docs/admin-deploy.md.
