# Админка POKRASKA.STORE

## Локальный запуск

1. Открой терминал в корне проекта.
2. Выполни:

```powershell
node scripts/admin-server.js
```

3. Открой:

```text
http://127.0.0.1:4173/admin/
```

По умолчанию сервер работает в локальном режиме без логина и пароля.

## Защищенный запуск для заказчика

Если нужно дать доступ заказчику или менеджеру, задай логин и пароль через переменные окружения.

PowerShell:

```powershell
$env:HOST = "0.0.0.0"
$env:PORT = "4173"
$env:ADMIN_USERNAME = "admin"
$env:ADMIN_PASSWORD = "StrongPasswordHere"
node scripts/admin-server.js
```

После этого:

- админка откроется по адресу `http://IP_СЕРВЕРА:4173/admin/`
- сохранение JSON будет доступно только после входа
- обычный сайт и JSON-контент продолжат открываться как раньше

## Что редактируется через админку

- общие настройки сайта: шапка, контакты, меню, футер
- главная страница
- каталог: группы и нижний CTA
- порошковая покраска и пескоструй
- автоматика и карточки товаров
- галерея: заголовок, фильтры, счетчик, CTA
- цены
- оплата и документы
- контакты

## Как давать доступ безопасно

Рекомендуемый вариант:

1. Запустить сервер на отдельной машине или VPS.
2. Закрыть прямой доступ по IP извне, если это возможно.
3. Открывать доступ заказчику через VPN, Tailscale или защищенный reverse proxy.
4. Использовать сложный пароль и менять его при необходимости.

## Ограничение текущей версии

В этой версии защищено именно редактирование через `/api/content/*`.
Сами JSON-файлы контента по адресу `/content/*.json` остаются публичными, потому что сайт читает их на клиенте.

Если позже понадобится полностью закрытая серверная админка и скрытый контент без публичных JSON, это уже следующий этап: перенос рендера на сервер или сборка статических HTML-файлов при публикации.
